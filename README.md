# ТГ Прокси — рабочие прокси для Telegram для всей семьи

Приложение для Android. В нём список проверенных MTProto-прокси и кнопка «Подключить». Сервер, порт и ключ копируются одним нажатием, а кнопка «Поделиться» отправляет прокси в семейный чат.

## Как это работает

- Робот на GitHub раз в 3 часа собирает прокси из открытых списков. Каждый он дважды проверяет настоящим подключением к Telegram и выкладывает рабочие в ветку `proxies`.
- Приложение берёт этот список и само перепроверяет прокси при открытии и каждые 4 минуты. Нерабочие оно убирает, самые быстрые ставит наверх.
- Если список с GitHub недоступен или в нём всё упало, приложение само ищет прокси в открытых списках.

## Как получить APK (один раз, около 40 минут, бесплатно)

1. Зарегистрируйтесь на github.com, если ещё нет аккаунта.
2. Справа вверху нажмите «+» → «New repository». Название любое, например `family-proxy`. Обязательно выберите **Public**, иначе телефоны не смогут скачивать список. Нажмите «Create repository».
3. На странице репозитория нажмите «uploading an existing file». Распакуйте ZIP на компьютере и перетащите в окно браузера **содержимое** папки `familyproxy`, а не саму папку: файлы `main.py`, `ui.kv`, `buildozer.spec`, `README.md`, `.gitignore` и папки `app`, `assets`, `data`, `tools`, `tests`, `.github`. Нажмите «Commit changes».
   - Проверьте, что в репозитории есть папка `.github/workflows` с двумя файлами. На Mac скрытые папки не видны: в Finder нажмите Cmd+Shift+. (точка).
   - Если папка так и не загрузилась: «Add file» → «Create new file», в имени напишите `.github/workflows/build-apk.yml`, вставьте содержимое этого файла из ZIP и сохраните. То же сделайте для `update-proxies.yml`.
4. Откройте вкладку **Actions**. Если GitHub спросит, нажмите «I understand my workflows, go ahead and enable them».
5. Слева выберите «Обновить список прокси» → «Run workflow». Через 5–10 минут появится ветка `proxies` со списком.
6. Слева выберите «Собрать APK» → «Run workflow». Первая сборка идёт 30–40 минут, следующие быстрее.
7. Когда сборка станет зелёной, APK появится в разделе **Releases** (справа на главной странице репозитория). Постоянная ссылка на последнюю версию выглядит так:
   `https://github.com/ВАШ_ЛОГИН/ИМЯ_РЕПОЗИТОРИЯ/releases/latest/download/FamilyProxy.apk`
   Её можно закрепить в семейном чате.

## Установка на телефон

1. Откройте ссылку на телефоне и скачайте `FamilyProxy.apk`.
2. Откройте файл. Android попросит разрешить установку из этого источника (браузера или Telegram). Разрешите.
3. Если Play Защита предупредит о неизвестном приложении, нажмите «Подробнее» → «Всё равно установить».

## Как пользоваться

- В списке сверху самые быстрые прокси. Зелёная точка означает, что прокси работает, рядом пинг.
- «Подключить» открывает Telegram. Там нажмите «Подключиться» (или «Включить прокси»).
- Нажмите на строку, и откроются сервер, порт и ключ. Нажмите на поле в рамке, и оно скопируется.
- «Поделиться» отправляет прокси в семейный чат. Родным достаточно нажать на ссылку, даже без приложения.
- «Обновить» ищет свежие прокси прямо сейчас.
- Совет: добавьте в Telegram 2–3 прокси из списка. Если один отвалится, можно быстро переключиться в настройках Telegram → «Данные и память» → «Прокси».

## Свой прокси (самый надёжный вариант)

Бесплатные прокси живут от нескольких часов до нескольких дней. Самый надёжный вариант — арендовать дешёвый сервер (VPS) и поставить на него MTProto-прокси, например mtg.

Чтобы закрепить свой прокси первым в списке:

1. На GitHub откройте файл `data/pinned.txt` → нажмите карандаш.
2. В новой строке (без `#` в начале) вставьте ссылку вида `tg://proxy?server=...&port=...&secret=...` → «Commit changes».
3. Во вкладке Actions запустите «Обновить список прокси».

Телефоны получат его сами, с пометкой «Свой». Переустанавливать приложение не нужно.

## Обновление приложения

Любое изменение файлов приложения на GitHub само запускает новую сборку. Новый APK ставится поверх старого. Если Android пишет «Приложение не установлено», удалите старую версию и поставьте новую. Так бывает, если GitHub потерял ключ подписи из кэша.

## Если что-то не работает

- В списке пусто и написано «Нет интернета» — проверьте интернет на телефоне.
- Робот перестал обновлять список. GitHub выключает расписание, если в репозитории 60 дней ничего не менялось: во вкладке Actions выберите «Обновить список прокси» и нажмите «Enable workflow».
- Отчёт робота (сколько нашлось, какие источники работают) лежит в ветке `proxies`, файл README.md.
- Сборка упала: откройте красную сборку в Actions. В конце шага «Сборка APK» видны строки с ошибкой, а полный лог можно скачать внизу страницы сборки (артефакт build-log). Приложите его в новом чате.

## Безопасность

Переписку владельцы прокси не видят, её шифрует сам Telegram. Но они видят IP-адрес и могут показывать в списке чатов свой рекламный канал («спонсор прокси»).

## Для разработчика

- `app/` — логика: разбор ссылок, проверка MTProto-рукопожатием, списки, кэш.
- `main.py` и `ui.kv` — интерфейс на Kivy.
- `tools/collect.py` — робот, `tools/make_icons.py` — значок и заставка.
- Тесты: `python3 -m unittest discover -s tests`
- Запуск на компьютере: `pip install kivy==2.3.0 certifi cryptography`, затем `python main.py`.
