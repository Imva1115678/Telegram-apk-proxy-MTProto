# 🛡️ ТГ Прокси: рабочие прокси для Telegram

Приложение для **Android**. В нём всегда свежий список проверенных прокси для Telegram. Нажали «Подключить», и Telegram работает. Без настроек и без технических знаний.

## ⬇️ Скачать

### 👉 [Скачать FamilyProxy.apk (последняя версия)](https://github.com/Imva1115678/Telegram-apk-proxy-MTProto/releases)

Другой способ: на главной странице репозитория справа нажмите **Releases** и скачайте файл **FamilyProxy.apk** из последнего релиза. Новые версии появляются там же.

> Приложение только для **Android**. Скачивать лучше с телефона, на который будете ставить.

## 📲 Как установить (1 минута)

1. Откройте ссылку выше на телефоне и скачайте файл `FamilyProxy.apk`.
2. Откройте скачанный файл. Android спросит разрешение на установку из этого источника (браузера или Telegram). Разрешите.
3. Если Play Защита пишет про неизвестное приложение, нажмите **«Подробнее» → «Всё равно установить»**.

## ▶️ Как пользоваться

1. Откройте приложение. Сверху стоят самые быстрые прокси.
2. **Зелёная точка** значит, что прокси работает. Рядом число (пинг): чем меньше, тем быстрее.
3. Нажмите **«Подключить»**. Откроется Telegram. Нажмите там **«Подключиться»** (или «Включить прокси»). Готово ✅

**Что ещё умеет приложение:**
- **Нажать на строку** с прокси: откроются сервер, порт и ключ. Нажмите на поле в рамке, и оно скопируется.
- **«Поделиться»**: отправляет прокси в семейный чат. Родным достаточно нажать на ссылку, даже без приложения.
- **«Обновить»**: ищет свежие прокси прямо сейчас.

💡 **Совет:** добавьте в Telegram 2–3 прокси из списка. Если один перестанет работать, переключитесь на другой: Telegram → «Данные и память» → «Прокси».

## ❓ Если что-то не работает

| Проблема | Что делать |
|---|---|
| В списке пусто, написано «Нет интернета» | Проверьте интернет на телефоне |
| «Приложение не установлено» при обновлении | Удалите старую версию и поставьте новую |
| Все прокси красные или не подключаются | Нажмите «Обновить» и подождите минуту. Бесплатные прокси живут от нескольких часов до нескольких дней |
| Новая версия не появляется | Откройте **Releases** и скачайте файл заново |

## 🔒 Безопасность

Переписку владельцы прокси **не видят**: её шифрует сам Telegram. Но владелец прокси видит ваш IP-адрес и может показывать в списке чатов свой рекламный канал («спонсор прокси»).

## 🧠 Как это работает

- Робот на GitHub раз в 3 часа собирает прокси из открытых списков. Каждый он дважды проверяет настоящим подключением к Telegram и выкладывает рабочие в ветку `proxies`.
- Приложение берёт этот список и само перепроверяет прокси при открытии и каждые 4 минуты. Нерабочие убирает, самые быстрые ставит наверх.
- Если список с GitHub недоступен, приложение само ищет прокси в открытых списках.

## 🛠 Для владельца репозитория

<details>
<summary><b>Как получить свою копию приложения (один раз, около 40 минут, бесплатно)</b></summary>

1. Зарегистрируйтесь на github.com, если ещё нет аккаунта.
2. Справа вверху нажмите **«+» → «New repository»**. Название любое (например, `family-proxy`). Выберите **Public**, иначе телефоны не смогут скачивать список. Нажмите **«Create repository»**.
3. Нажмите **«uploading an existing file»**. Распакуйте ZIP и перетащите в окно браузера **содержимое** папки `familyproxy` (не саму папку): `main.py`, `ui.kv`, `buildozer.spec`, `README.md`, `.gitignore` и папки `app`, `assets`, `data`, `tools`, `tests`, `.github`. Нажмите **«Commit changes»**.
   - Проверьте, что есть папка `.github/workflows` с двумя файлами. На Windows включите **Вид → Показать → Скрытые элементы**, на Mac в Finder нажмите **Cmd+Shift+.**
   - Если папка не загрузилась: **Add file → Create new file**, в имени напишите `.github/workflows/build-apk.yml`, вставьте содержимое файла из ZIP и сохраните. То же сделайте для `update-proxies.yml`.
4. Откройте вкладку **Actions**. Если GitHub спросит, нажмите **«I understand my workflows, go ahead and enable them»**.
5. Слева выберите **«Обновить список прокси» → «Run workflow»**. Через 5–10 минут появится ветка `proxies` со списком.
6. Слева выберите **«Собрать APK» → «Run workflow»**. Первая сборка идёт 30–40 минут, следующие быстрее.
7. Когда сборка станет зелёной, APK появится в **Releases**. Ссылку на последнюю версию можно закрепить в семейном чате:
   `https://github.com/ВАШ_ЛОГИН/ИМЯ_РЕПОЗИТОРИЯ/releases/latest/download/FamilyProxy.apk`

**Если сборка падает или Releases пустой:** в **Settings → Actions → General** включите **Read and write permissions** и запустите сборку снова. Если сборка красная, откройте красный шаг в Actions и скопируйте последние 100 строк лога.

</details>

<details>
<summary><b>Свой прокси (самый надёжный вариант)</b></summary>

Бесплатные прокси нестабильны. Надёжнее арендовать дешёвый сервер (VPS) и поставить на него MTProto-прокси, например mtg.

Чтобы закрепить свой прокси первым в списке:

1. Откройте файл `data/pinned.txt` и нажмите карандаш.
2. В новой строке (без `#` в начале) вставьте ссылку вида `tg://proxy?server=...&port=...&secret=...` → **Commit changes**.
3. Во вкладке **Actions** запустите **«Обновить список прокси»**.

Телефоны получат его сами, с пометкой «Свой». Переустанавливать приложение не нужно.

</details>

<details>
<summary><b>Обновления и если робот остановился</b></summary>

- Любое изменение файлов приложения на GitHub само запускает новую сборку. Новый APK ставится поверх старого.
- Если список прокси перестал обновляться: GitHub выключает расписание, если в репозитории 60 дней ничего не менялось. Во вкладке **Actions** выберите **«Обновить список прокси»** и нажмите **«Enable workflow»**.
- Отчёт робота (сколько нашлось, какие источники работают) лежит в ветке `proxies`, файл `README.md`.

</details>

<details>
<summary><b>Для разработчика</b></summary>

- `app/`: логика (разбор ссылок, проверка MTProto-рукопожатием, списки, кэш).
- `main.py` и `ui.kv`: интерфейс на Kivy.
- `tools/collect.py`: робот, `tools/make_icons.py`: значок и заставка.
- Тесты: `python3 -m unittest discover -s tests`
- Запуск на компьютере: `pip install kivy==2.3.0 certifi cryptography`, затем `python main.py`.

</details>
