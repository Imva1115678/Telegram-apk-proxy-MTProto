# Чекпоинт 4 — исправлена сборка APK

Если чат оборвался: в новом чате прикрепите этот ZIP и напишите «продолжи». Если сборка упала — приложите ещё файл build-log (артефакт внизу страницы сборки в Actions) или конец лога из шага «Сборка APK».

## Что это

«ТГ Прокси» — Android-приложение для семейного чата (Python + Kivy, APK собирается на GitHub Actions).

- Список рабочих MTProto-прокси: название, статус с пингом, кнопка «Подключить».
- Экран прокси: сервер, порт и ключ в рамках. Нажал — скопировалось, рамка подсвечивается синим.
- «Поделиться», «Скопировать ссылку», «Проверить ещё раз».
- Светлая тема, синие кнопки, синяя верхняя панель. Цвета проверены на контраст (WCAG AA).

Ответы пользователя: собирать через GitHub; у всех в семье Android; светлая тема.

## Чекпоинт 4: что исправлено

Первая сборка на GitHub («Собрать APK #2») упала через 10 минут на шаге сборки.

- Причина: в buildozer.spec не была закреплена версия python-for-android, и buildozer взял самую свежую (master). Она собирает для телефона Python 3.14.2 с NDK 28c, а Kivy 2.3.0 и Cython 0.29.36 с Python 3.14 не собираются. Сам текст ошибки GitHub обрезал (лог слишком большой), но по логу видно, что всё до сборки прошло нормально и файлы загружены правильно.
- Закреплена проверенная связка: python-for-android 2024.01.21 (Python 3.11) + NDK 25b. Workflow сам скачивает эту версию (тег v2024.01.21, запасной вариант release-2024.01.21) и подставляет p4a.source_dir в buildozer.spec.
- Лог больше не обрезается: полный лог пишется в build.log, на экране только ход сборки. Если сборка упала, в конце шага видны строки с ошибками и последние 150 строк, конец лога есть в Summary, а полный лог лежит в артефакте build-log.
- В начале сборки проверяется, что все файлы проекта загрузились.
- Ключи кэша сменены на v2.
- Код приложения и робота проверен на совместимость с Python 3.11 (на телефоне будет 3.11).

- Все тесты проходят: `python3 -m unittest discover -s tests`.
- Синтаксис всех .py, YAML обоих воркфлоу, buildozer.spec, структура ui.kv (отступы, выражения, все классы и методы app.* существуют).
- Значок и заставка просмотрены.
- Шаги сборки из workflow прогнаны здесь с подставным buildozer: успешная сборка, падение (видна ошибка, пишется Summary), проверка файлов, скачивание python-for-android с запасным тегом.

## Что не проверено (в песочнице нет интернета)

- Интерфейс Kivy не запускался: Kivy не установить без интернета. Первая сборка APK — первая настоящая проверка экрана.
- Настоящие прокси из интернета проверит робот при первом запуске (в отчёте в ветке proxies видно, сколько работает).
- Настоящую сборку с python-for-android 2024.01.21 здесь не запустить — её проверит следующий запуск «Собрать APK».

## Что проверить после первой сборки

1. Приложение открывается, сверху синяя панель, под ней строка статуса.
2. За 1–2 минуты появляются прокси с «● Работает · N мс».
3. «Подключить» открывает Telegram с окном прокси.
4. На экране прокси поля копируются и подсвечиваются; «Назад» возвращает к списку.
5. «Поделиться» открывает системное окно выбора приложения.

Если приложение закрывается сразу после запуска — подключите телефон к компьютеру и снимите лог: `adb logcat -s python`, либо просто опишите, что происходит.
